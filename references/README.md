# Scripts EM4 de base — référence locale

Les fichiers de `references/em4_base/` proviennent du dossier
`03_SCRIPTS_EM4/base/` de l'archive `03_SCRIPTS_EM4.zip` fournie pour ce
projet. L'arborescence d'origine est conservée. Elle contient **134 scripts
texte `.script`** du jeu de base.

Ces scripts servent d'exemples de **logique de jeu** à étudier puis à
réimplémenter en Luau dans `src/` : commandes, conditions d'action, états et
conséquences. Ils ne font pas partie du projet Rojo, ne sont pas exécutés par
ERS et ne doivent pas être copiés tels quels dans le jeu.

Ce dossier est **local et ignoré par Git** pour éviter de redistribuer les
sources d'un jeu tiers. Les 24 `.pscript` binaires, les autres fichiers de
l'archive et les scripts du mod CSP-IRG n'ont pas été ajoutés. Toute nouvelle
fonctionnalité ERS inspirée de ces exemples doit être écrite pour Roblox et
vérifiée avec les tests du projet.
